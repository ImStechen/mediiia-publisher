# История изменений

## 0.1.1 — 2026-09-11

- ссылка на запись и код VK Видео больше не обязательны: записи бывает и не будет,
  а строка готовности пишет, без чего уходит черновик;
- вход держится: пропуск Mediiia живёт час, поэтому программа запоминает аккаунт
  и продлевает вход молча, не открывая окно браузера;
- вход больше не сохраняет просроченный токен из браузера: раньше это выглядело
  как успешный вход, а создание черновика падало с ошибкой 401;
- если в браузере остался старый токен, программа ждёт, пока сайт выдаст свежий;
- `account_id` берётся из токена, а не из случайной ссылки на странице —
  черновик гарантированно создаётся на своём аккаунте;
- вход больше не создаёт пустой черновик на аккаунте;
- понятное сообщение вместо `HTTP 401`.

## 0.1.0 — 2026-09-10

- импорт `.docx`, `.txt` и текста из буфера;
- детерминированная разметка абзацев, `<h3>`, цитат и зелёных плашек;
- служебная концовка, VK Видео и инфопартнёры;
- создание неопубликованного черновика через API Mediiia;
- вход под разными аккаунтами с защищённым хранением пароля через Windows DPAPI;
- выбор Google Chrome или Microsoft Edge;
- фирменный интерфейс HSE Creative Hub с предпросмотром и проверкой готовности;
- portable-сборка, офлайн- и онлайн-установщики для Windows.
