# Mediiia публикатор

Десктоп-утилита для Креативного хаба НИУ ВШЭ: берёт статью от Gemini (вставка / `.txt` / `.docx`), **детерминированно** режет на блоки Mediiia, добавляет служебную концовку и создаёт **черновик** на [mediiia.com](https://mediiia.com).

Фото, обложку и кнопку публикации оставляете себе — программа их не трогает.

## Зачем

Gemini хорошо пишет текст по вашему промпту (`**жирное**`, цитаты через `>`), но не должен отвечать за разметку сайта. Алгоритм сам:

1. Берёт первую короткую строку → название проекта
2. Абзацы → блоки `normal`
3. Строки `>` и абзацы в «кавычках» → штатные блоки `quote` с именем спикера
4. `**текст**` → `<strong>текст</strong>`
5. Склеивает подзаголовки с текстом и разбивает длинные полотна пустыми строками
6. Добавляет референсное вступление, зелёные плашки, запись, доп. информацию, инфопартнёров и видео
7. Создаёт проект через API Mediiia, заливает блоки и открывает редактор в выбранном браузере

## Скачать для Windows

Готовые файлы находятся на странице
[последнего релиза](https://github.com/ImStechen/mediiia-publisher/releases/latest):

- `MediiiaPublisher-portable.zip` — portable: распаковать и запустить
  `MediiiaPublisher.exe`, установка не нужна;
- `MediiiaPublisher-Setup.exe` — полный офлайн-установщик;
- `MediiiaPublisher-WebSetup.exe` — маленький установщик, который скачивает
  актуальную portable-сборку с GitHub.

Требования: Windows 10/11 x64, Google Chrome или Microsoft Edge, интернет.
Chrome/Edge не входят в сборку — поэтому portable остаётся сравнительно
лёгкой. Браузер выбирается в карточке «Параметры», выбор запоминается.

## Установка (разработка)

```powershell
cd C:\Users\ASA\Desktop\Cursor\mediiia-publisher
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Скопируйте конфиг:

```powershell
copy config.example.json config.json
```

## Запуск

```powershell
python main.py
```

Только проверить разбор файла:

```powershell
python main.py --parse ".\9 сентября.docx"
python main.py --file ".\9 сентября.docx" --title "Название статьи"
```

## Как пользоваться

1. В «Параметрах» выберите **Google Chrome** или **Microsoft Edge**. Нажмите чип аккаунта в правом верхнем углу — откроется окно входа в выбранном браузере. Введите почту и пароль того аккаунта, от которого публикуете. Галочка «Запомнить» шифрует пароль средствами Windows (DPAPI) в `%USERPROFILE%\.mediiia-publisher\credentials.json`; пароль можно не сохранять и вводить каждый раз.
2. Перетащите `.docx` в окно, нажмите **Ctrl+V** или **Выбрать файл…**. Разбор запускается сам, кнопки «Разобрать» больше нет.
3. Заполните поля с меткой **нужно**: заголовок, дата ивента, ссылка на запись и код вставки VK Видео (целиком, в виде `<iframe …></iframe>`). Доп. информация и инфопартнёры — по желанию.
4. Справа — предпросмотр всех блоков: подзаголовки, цитаты с именем спикера, плашки и концовка. Он пересчитывается на каждое изменение полей. Переключатель **Блоки / Исходник** показывает сырой текст, его тоже можно править.
5. Внизу — чеклист готовности. Пока в нём есть красные пункты, кнопка **Создать черновик** неактивна: так забытый код видео не уедет в статью.
6. **Создать черновик** — без публикации. Во время заливки видно, какой блок отправляется; после — ссылка на черновик с кнопками открытия в выбранном браузере и копирования ссылки.
7. В редакторе добавьте обложку и фото, проверьте текст, опубликуйте.

Кнопка **Сбросить всё** в футере стирает загруженный текст и все заполненные поля. Перед этим она показывает список того, что будет стёрто, и по умолчанию выбран «Нет». Пока сбрасывать нечего, кнопка неактивна; во время заливки черновика — тоже.

Горячие клавиши: `Ctrl+O` — файл, `Ctrl+V` — вставить текст, `F5` — перечитать файл, `Ctrl+Enter` — создать черновик.

### Инфопартнёры

Вставляйте одной строкой в том виде, в каком получаете:

```
CLOZE | Локальные бренды (https://t.me/clozesstore), Школа индустрии моды Розмари Турман (https://t.me/howfashionworks)
```

Разделителем считается сама ссылка в скобках, поэтому запятые и `|` внутри названия канала разбор не ломают. На выходе — блок вида `*<strong><a href="...">Название</a></strong>`, как в опубликованных статьях.

### Служебные блоки

- Промокод CREATIVE HUB — зелёная плашка `colored` `#3ccd29`, если включена галочка в «Параметрах».
- Референсное вступление с датой, площадкой и названием — если указана дата.
- Ссылка на запись и написанная редактором доп. информация — обычный текстовый блок.
- Инфопартнёры — если поле заполнено.
- Видео — только если вставлен готовый VK-код `<iframe …></iframe>`.
- «Мероприятие прошло …» — финальная зелёная плашка, если указана дата.

Тексты шаблонов лежат в `config.json` → `article_tail`, значения по умолчанию — в `src/config.py`.

## Сборка для Windows

```powershell
pip install -r requirements.txt
pip install pyinstaller pillow
winget install --id JRSoftware.InnoSetup --exact
powershell -ExecutionPolicy Bypass -File .\packaging\build.ps1
```

Скрипт создаёт в `release/` portable ZIP, офлайн- и онлайн-установщики.
Встроенный Chromium не скачивается и не упаковывается: Playwright управляет
установленным Chrome или Edge.

## Ограничения

- API Mediiia внутренний и без публичной документации — при смене бэкенда может понадобиться правка клиента.
- Теги берутся по ID из `config.json` → `default_tag_ids` (надёжнее, чем поиск по названию). Если тег переименуют, ID останется рабочим.
- Картинки и обложка программой не загружаются (намеренно).
- Черновик создаётся со статусом «не опубликовано»; публикация — только руками.

## Структура

- `src/parser.py` — разбор текста / Word, служебная концовка, инфопартнёры
- `src/auth.py` — вход через Chrome/Edge, отдельный постоянный профиль на каждый аккаунт
- `src/browsers.py` — выбор браузера и открытие ссылок
- `src/credentials.py` — логин/пароль, пароль под DPAPI
- `src/mediiia_api.py` — создание проекта, тегов и блоков
- `src/gui.py` — окно
- `src/theme.py` — палитра, типографика и метрики Креативного хаба
- `main.py` — точка входа
- `tools/` — служебные скрипты: разбор опубликованных статей, проверка черновика, автоматизация окна
- `packaging/` — PyInstaller, portable и два Inno Setup-установщика
