# Mediiia публикатор

Десктоп-утилита для Креативного хаба НИУ ВШЭ: берёт статью от Gemini (вставка / `.txt` / `.docx`), **детерминированно** режет на блоки Mediiia, добавляет служебную концовку и создаёт **черновик** на [mediiia.com](https://mediiia.com).

Фото, обложку и кнопку публикации оставляете себе — программа их не трогает.

## Зачем

Gemini хорошо пишет текст по вашему промпту (`**жирное**`, цитаты через `>`), но не должен отвечать за разметку сайта. Алгоритм сам:

1. Берёт первую короткую строку → название проекта
2. Абзацы → блоки `normal`
3. Строки `>` и абзацы в «кавычках» → штатные блоки `quote` с именем спикера
4. `**текст**` → `<strong>текст</strong>`
5. Склеивает подзаголовки с текстом и разбивает длинные полотна пустыми строками
6. Добавляет референсное вступление, зелёные плашки, запись, доп. информацию, инфопартнёров и видео
7. Создаёт проект через API Mediiia, заливает блоки и открывает редактор в выбранном браузере

## Установка на Windows

Нужны **Windows 10 или 11 (x64)**, интернет и уже установленный **Google Chrome** или **Microsoft Edge**. Браузер в программу не входит — поэтому сборка остаётся лёгкой. Какой браузер использовать, выбираете в карточке «Параметры».

Скачайте файл на странице [последнего релиза](https://github.com/ImStechen/mediiia-publisher/releases/latest). Если Windows Defender или SmartScreen спросит «неизвестный издатель» — это обычная реакция на программу без цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».

### Portable — без установки

Подходит, если не хотите ничего ставить в систему: можно держать на флешке или в папке на рабочем столе.

1. Скачайте [`MediiiaPublisher-portable.zip`](https://github.com/ImStechen/mediiia-publisher/releases/latest/download/MediiiaPublisher-portable.zip).
2. Распакуйте архив в любую папку, например `C:\Programs\MediiiaPublisher`. Не запускайте `.exe` прямо из окна архива — сначала распакуйте.
3. Откройте папку и запустите **`MediiiaPublisher.exe`**.

Папку можно переименовать и переносить. Логин, сессия и выбор браузера хранятся отдельно, в `%USERPROFILE%\.mediiia-publisher`, и не удаляются вместе с папкой.

### Полный установщик — без интернета при установке

Подходит, если ставите на компьютер без доступа к GitHub или хотите ярлык в меню «Пуск».

1. Скачайте [`MediiiaPublisher-Setup.exe`](https://github.com/ImStechen/mediiia-publisher/releases/latest/download/MediiiaPublisher-Setup.exe) (~45 МБ).
2. Запустите файл. Права администратора не нужны.
3. Примите папку по умолчанию (`%LOCALAPPDATA%\Programs\Mediiia Publisher`) или укажите свою.
4. По желанию отметьте ярлык на рабочем столе.
5. После установки программа откроется сама. Дальше её можно запускать из меню «Пуск» → **Mediiia публикатор**.

### Маленький установщик — скачивает программу с GitHub

Подходит, если хотите короткий файл (~2 МБ) и всегда свежую версию с GitHub. На компьютере должен быть интернет.

1. Скачайте [`MediiiaPublisher-WebSetup.exe`](https://github.com/ImStechen/mediiia-publisher/releases/latest/download/MediiiaPublisher-WebSetup.exe).
2. Запустите файл. Права администратора не нужны.
3. Установщик сам скачает `MediiiaPublisher-portable.zip` с GitHub и распакует его в `%LOCALAPPDATA%\Programs\Mediiia Publisher`.
4. После установки программу можно запускать из меню «Пуск».

### Что выбрать

| Файл | Когда брать |
|---|---|
| `MediiiaPublisher-portable.zip` | Не ставить в систему, переносить папкой |
| `MediiiaPublisher-Setup.exe` | Обычная установка, компьютер может быть без GitHub |
| `MediiiaPublisher-WebSetup.exe` | Короткий файл, установка с интернетом |

### Удаление

- Установщик: «Параметры Windows» → «Приложения» → **Mediiia публикатор** → «Удалить», либо `unins000.exe` в папке программы.
- Portable: просто удалите папку с программой.

Данные аккаунта при этом остаются в `%USERPROFILE%\.mediiia-publisher`. Чтобы выйти полностью, удалите и эту папку.

## Установка из исходников (для разработки)

```powershell
git clone https://github.com/ImStechen/mediiia-publisher.git
cd mediiia-publisher
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Скопируйте конфиг:

```powershell
copy config.example.json config.json
```

## Запуск

```powershell
python main.py
```

Только проверить разбор файла:

```powershell
python main.py --parse ".\9 сентября.docx"
python main.py --file ".\9 сентября.docx" --title "Название статьи"
```

## Как пользоваться

1. В «Параметрах» выберите **Google Chrome** или **Microsoft Edge**. Нажмите чип аккаунта в правом верхнем углу — откроется окно входа в выбранном браузере. Введите почту и пароль того аккаунта, от которого публикуете. Галочка «Запомнить» шифрует пароль средствами Windows (DPAPI) в `%USERPROFILE%\.mediiia-publisher\credentials.json`; пароль можно не сохранять и вводить каждый раз. Входить каждый раз не нужно: пропуск Mediiia живёт всего час, но программа помнит аккаунт и продлевает вход сама, без окна браузера.
2. Перетащите `.docx` в окно, нажмите **Ctrl+V** или **Выбрать файл…**. Разбор запускается сам, кнопки «Разобрать» больше нет.
3. Заполните поля с меткой **нужно**: заголовок и дата ивента. Ссылка на запись, код вставки VK Видео (целиком, в виде `<iframe …></iframe>`), доп. информация и инфопартнёры — по желанию: записи бывает и не будет. Чего не хватает, футер напишет прямо в строке готовности — например «без ссылки на запись и видео».
4. В карточке «Плашки и параметры» отдельно выберите верхнюю и нижнюю зелёные плашки. Есть варианты из опубликованных статей: промокод, открытые вебинары, Telegram-бот с материалами, сайт или Telegram-канал хаба; у каждой позиции есть «Свой текст» и «Без плашки».
5. Справа — предпросмотр всех блоков: подзаголовки, цитаты с именем спикера, плашки и концовка. Он пересчитывается на каждое изменение полей. Переключатель **Блоки / Исходник** открывает визуальный редактор текста статьи.
6. Внизу — чеклист готовности. Пока в нём есть красные пункты, кнопка **Создать черновик** неактивна. Ссылка на запись и видео необязательны и показываются серым.
7. **Создать черновик** — без публикации. Во время заливки видно, какой блок отправляется; после — ссылка на черновик с кнопками открытия в выбранном браузере и копирования ссылки.
8. В редакторе добавьте обложку и фото, проверьте текст, опубликуйте.

Кнопка **Сбросить всё** в футере стирает загруженный текст и все заполненные поля. Перед этим она показывает список того, что будет стёрто, и по умолчанию выбран «Нет». Пока сбрасывать нечего, кнопка неактивна; во время заливки черновика — тоже.

Горячие клавиши: `Ctrl+O` — файл, `Ctrl+V` — вставить текст, `F5` — перечитать файл, `Ctrl+Enter` — создать черновик. В визуальном редакторе: `Ctrl+B` — жирный, `Ctrl+I` — курсив, `Ctrl+K` — встроить ссылку, `Ctrl+Z` и `Ctrl+Shift+Z` — отменить и повторить (вместе с форматированием).

### Форматирование и ссылки

Панель `B / I / Ссылка / H3 / Цитата` есть у исходника статьи и поля
«Дополнительно». Выделите текст и нажмите кнопку. Для ссылки откроется поле
адреса; пустой адрес снимает существующую ссылку. Вариант «Свой текст» у
зелёной плашки также поддерживает жирный, курсив и ссылки.

Правый предпросмотр показывает форматирование до отправки. Ссылки в нём
кликабельны и открываются в выбранном Chrome или Edge.

### Инфопартнёры

Можно нажать **Добавить партнёра** и отдельно ввести название и ссылку.
Либо вставьте готовый список одной строкой в том виде, в каком получаете:

```
CLOZE | Локальные бренды (https://t.me/clozesstore), Школа индустрии моды Розмари Турман (https://t.me/howfashionworks)
```

Разделителем считается сама ссылка в скобках, поэтому запятые и `|` внутри названия канала разбор не ломают. На выходе — блок вида `*<strong><a href="...">Название</a></strong>`, как в опубликованных статьях.

### Служебные блоки

- Верхняя зелёная плашка `colored` `#3ccd29`: промокод CREATIVE HUB, Telegram-бот с материалами, открытые вебинары, свой текст или без плашки.
- Референсное вступление с датой, площадкой и названием — если указана дата.
- Ссылка на запись и написанная редактором доп. информация — обычный текстовый блок.
- Инфопартнёры — если поле заполнено.
- Видео — только если вставлен готовый VK-код `<iframe …></iframe>`.
- Нижняя зелёная плашка: «Мероприятие прошло …» со ссылкой на сайт или Telegram-канал хаба, свой текст либо без плашки.

Тексты шаблонов лежат в `config.json` → `article_tail`, значения по умолчанию — в `src/config.py`.

## Сборка для Windows

```powershell
pip install -r requirements.txt
pip install pyinstaller pillow
winget install --id JRSoftware.InnoSetup --exact
powershell -ExecutionPolicy Bypass -File .\packaging\build.ps1
```

Скрипт создаёт в `release/` portable ZIP, офлайн- и онлайн-установщики.
Встроенный Chromium не скачивается и не упаковывается: Playwright управляет
установленным Chrome или Edge.

## Ограничения

- API Mediiia внутренний и без публичной документации — при смене бэкенда может понадобиться правка клиента.
- Теги берутся по ID из `config.json` → `default_tag_ids` (надёжнее, чем поиск по названию). Если тег переименуют, ID останется рабочим.
- Картинки и обложка программой не загружаются (намеренно).
- Черновик создаётся со статусом «не опубликовано»; публикация — только руками.

## Структура

- `src/parser.py` — разбор текста / Word, служебная концовка, инфопартнёры
- `src/auth.py` — вход через Chrome/Edge, отдельный постоянный профиль на каждый аккаунт
- `src/browsers.py` — выбор браузера и открытие ссылок
- `src/credentials.py` — логин/пароль, пароль под DPAPI
- `src/mediiia_api.py` — создание проекта, тегов и блоков
- `src/gui.py` — окно
- `src/rich_text.py` — визуальное форматирование и безопасная сериализация ссылок
- `src/theme.py` — палитра, типографика и метрики Креативного хаба
- `main.py` — точка входа
- `tools/` — служебные скрипты: разбор опубликованных статей, проверка черновика, автоматизация окна
- `packaging/` — PyInstaller, portable и два Inno Setup-установщика
